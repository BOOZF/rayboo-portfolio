浏览时会收集什么

网站本身不收集任何信息。没有 Cookie、没有分析工具、没有广告像素，也不会在你的浏览器存储中保存任何内容。字体、图片和 3D 模型都由本网站直接提供，因此浏览时不会连接任何第三方。

本网站托管在 Vercel 上。和所有网站托管商一样，Vercel 会自动处理技术性请求数据（例如你的 IP 地址、浏览器类型和访问的页面），用于提供网站服务、保障安全并防止滥用。详见 Vercel 的隐私政策。

「问问 Ray」助手

如果你使用聊天助手，你输入的问题会发送到本网站的服务器，再发送给 OpenAI 的 API，由它根据 Ray 工作的相关事实生成回答。请不要在其中输入个人或敏感信息。

  • 本网站不会保存你的问题和回答。
  • 你的 IP 地址会在内存中保留约一分钟，用于限制提问频率，之后即被丢弃。
  • OpenAI 会处理问题以生成回答。根据其 API 条款，通过 API 发送的数据默认不会用于训练模型，并可能为防止滥用而保留一段有限的时间。详见 OpenAI 的隐私政策。
