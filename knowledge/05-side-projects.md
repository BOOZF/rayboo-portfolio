# Side projects

## RunForPeace
A personal side project (2025): the web platform for Run for Peace, a nationwide charity fun run in Malaysia. Ray did the UI/UX design and frontend development, and engineered the event registration and landing page to handle more than 1 million user interactions. He built a RAG agent into the site that answers runners' questions about the event. Link: https://runforpeace.com.my/

## Other builds
Ray also built a Form App in React Native with Prisma, with the UI/UX designed from scratch, and a sales dashboard with seasonal pricing controls that update the live site in real time.
