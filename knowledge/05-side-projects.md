# Side projects

## RunForPeace
A personal side project (2025): the web platform for Run for Peace, a nationwide charity fun run in Malaysia. Ray took part in the UI/UX design and frontend development, and the event registration and landing page were engineered to handle more than 1 million user interactions. He integrated a Retrieval-Augmented Generation (RAG) agent into the site that gives intelligent responses and event assistance to runners. He also contributed to testing, deployment and user-experience refinement ahead of the launch. Link: https://runforpeace.com.my/

## Form App
A mobile form management system built in React Native for cross-platform use. Ray designed the entire UI/UX from scratch for a clean, user-friendly interface and smooth form interactions. He integrated backend services with Prisma for database management and automatic type-safe API generation, and led the frontend and backend API integration, enabling dynamic form generation, submission tracking and user-specific workflows.

## Sales dashboard and pricing back office
A backend system with a dashboard that lets users track sales performance and filter data by date range. Ray implemented admin features to customise pricing dynamically based on seasonal factors, with the changes reflected on the end-user website in real time.
